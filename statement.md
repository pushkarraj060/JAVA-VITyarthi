# Problem Statement

Students often lose personal belongings on campus, while found items may not reach their owners efficiently. The Smart Campus Lost & Found system provides a centralized Java application for reporting, searching, matching, and claiming lost and found items.

## Objectives

1. Provide an easy way to report lost items.
2. Allow students to report found items.
3. Help users search for relevant reports.
4. Calculate possible matches between lost and found items.
5. Provide a claim and verification workflow.
6. Allow administrators to manage reports and claims.

## Major Modules

- Authentication and User Management
- Lost/Found Item Management
- Matching Service
- Claim Management
- Admin Management and Statistics

## Non-Functional Requirements

- Usability
- Reliability
- Maintainability
- Error handling
- Performance

## Future Enhancements

- GUI using JavaFX or Swing
- MySQL database
- Email notifications
- Image upload for items
- QR-code based claim verification
